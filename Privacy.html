Privacy Policy for RandomTyms Transfer Last updated: August 12, 2026 RandomTyms Transfer is a personal tool to migrate GIFs owned by RandomTyms from Tenor to Pinterest. Information We Collect We do not collect, store, or share any personal information from users. The app only uses Pinterest OAuth tokens provided by the owner to create Pins on their own boards. How We Use Information The access token is used solely to authenticate with the Pinterest API v5 to list boards and create pins. No data is sent to any third-party server. Data Storage No user data is stored on any server. All operations run locally on the user's device. Third-Party Services This app uses Pinterest API and Tenor.com (for source GIFs owned by RandomTyms). Please refer to Pinterest's Privacy Policy and Tenor's Terms for their respective data handling.
