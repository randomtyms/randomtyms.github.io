### 🛠️ Architecture & Integration

* **3D Simulation Core:** Built using Three.js to render celestial spheres, dynamic orbits, and smooth camera tweening.
* **Content Integration:** Connected directly with RandomTyms educational YouTube Shorts to deliver context-aware bite-sized learning when planets are explored.
* **Co-Created via Mobile Prompts:** Architected and integrated with AI assistance (@grok) entirely on a mobile phone, proving advanced web interactives can be shipped without high-end development hardware.

---

### 🎯 Who It's For

* **Class 3–8 Learners:** Explore planetary distances and characteristics in 360°.
* **Classrooms & Smartboards:** Freeze orbital paths mid-motion for interactive Q&A sessions.
* **Parents:** Safe screen-time utility accessible instantly in any mobile browser without installs.

---

### 🎮 Controls

* **Drag:** Orbit camera view across the full solar plane.
* **Tap Planet / Chip:** Smooth fly-to camera focus on celestial bodies.
* **Pause / Play:** Freeze celestial motion in real time.
* **Speed Select (Slow / Medium / Fast):** Toggle orbital speeds to observe comparative velocity.
* **See All:** Reset view to wide-angle perspective.

*(Scale distances and orbital radii are visually compressed for seamless interaction on mobile screens.)*
